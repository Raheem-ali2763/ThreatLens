# Security Policy

## Purpose

ThreatLens is a defensive cybersecurity project intended for educational, portfolio and authorized security testing.

## Responsible Use

Only use ThreatLens and its security-testing capabilities against systems and data for which you have explicit authorization.

## Secrets

Never commit:

- API keys
- Passwords
- JWT secrets
- Database credentials
- Access tokens

Sensitive configuration should be stored in a local `.env` file.

## Reporting

Security issues should be documented and reported responsibly.
